# homebrew-tap

Homebrew tap for [Caffeinate UI](https://github.com/harinaralasetty/caffeinate-ui) and [Underhood](https://github.com/harinaralasetty/underhood).

```sh
brew install --cask harinaralasetty/tap/caffeinate-ui
```

Apple Silicon, macOS 13+. The app is not signed with a Developer ID or notarized, so macOS may block the first launch: open System Settings > Privacy & Security and choose "Open Anyway".

## Underhood

Offline static inspector for macOS apps and Windows executables. macOS and Linux, Apple silicon / arm64 and Intel / amd64.

```sh
brew install harinaralasetty/tap/underhood
```
